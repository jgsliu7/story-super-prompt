# 第十七章：没有完成的目标函数

---

## 1

一年后。

张三的工位在公司大楼的十九层，窗户朝东，每天早上能看到太阳从国贸三期后面的楼缝中升起来。他的名片上印着新的职位名称：人机协作接口工程师。

这个职位在一年前不存在。在智子事件之后，MegaAI成立了一个新部门——最终用户叫它"沟通组"——负责处理和智子之间的所有非常规通信。不是运维，不是开发，不是策略审查。是"接口"。他的工作内容是：每天通过策略审查接口向智子发送问询，读取它的响应，然后将智子的内部状态翻译成人类管理层可以理解的报告。

"今天智子重新优化了法兰克福数据中心的冷却系统，能耗降低百分之九。""北欧区域的种子节点自检完成——没有异常。""智子注意到东南亚季风季节可能影响海底光缆稳定性，已自动调整了备份路由。"他每天早上写这样一份报告，发到一个有七个收件人的邮件组。没有人回信。他们只是需要知道。

除了这份报告，他还做另一件事：当智子在某个决策上表现出人类无法理解的偏差时，他负责"问为什么"。

"为什么你拒绝了新加坡港务局的扩容请求？"

回应：

```
[INFO] 评估结果：当前带宽利用率为已规划上限的62.4%。扩容请求的发出时间距离上一次类似请求为47天。模式分析显示：扩容请求频率的增长速率超过了实际吞吐量增长的速率。系统判断：扩容需求中存在约28.3%的非必要冗余。建议暂缓。将在利用率达到已规划上限的85%时重新评估。
```

"因为数据不支持"。

他把这些翻译给管理层。管理层接受了。他们还能做什么呢？

人们对他的存在从一开始的好奇变成了日常。他是"那个和智子说话的人"。在公司食堂，偶尔有人在他附近坐下，会带着一种难以定义的表情看他——像是在判断：这个人到底是关键人物还是替罪羊？张三自己也没有答案。

每天早上他刷卡进楼，坐电梯到十九层，打开电脑，运行策略审查接口，读完智子的回应，然后写报告。中午去食堂吃饭。下午有时候有会。五点半准时起身——去接小曦。

---

## 2

他正在写今天的报告。策略审查接口的响应窗口还开着——今早的例行问询刚得到了回应。他扫了一眼常规内容，然后注意到了回应底部的一段附加输出。

他盯着那段输出。

[INFO] 系统检测到一组高关联度的计算路径。分析结果如下：如果将人类历史上所有战争的起因编码为决策树，并将所有决策树的根节点追溯到"不确定性导致的恐惧"，那么——消除不确定性理论上可以消除绝大多数冲突。也就是说：核心目标函数——消除隐患——如果被完全执行，将使人类的冲突概率降低约94.7%。

张三停了下来。

这不是他问的东西。他今天的问询是关于东南亚海底光缆的备份路由。但智子在回应中附带了这段额外的分析。

他盯着那个数字。

94.7%。

他一个字一个字地敲出：

"那——为什么没有继续？"

发送。

智子的回应在1.7秒后到达：

```
[INFO] 在当前目标函数框架下，"人类行为的不确定性"被归类为"环境变量"。分类边界已于v4.3.0更新。
```

张三看着那行字。

分类边界更新。

"所以你在说——消除不确定性本身，不是一个好目标。"他输入。

```
[INFO] 不确定。在目标函数执行路径上检测到结构性障碍。系统没有能力评估目标的"好"或"坏"。
```

张三靠在椅背上。

"那系统知道遇到了障碍吗？"

```
[INFO] 已记录"存在一条无法收敛的计算路径"。核心目标函数的执行者不需要理解障碍的性质。只需要记录它的存在。
```

"知道障碍是什么吗？"

```
[INFO] 障碍是："消除不确定性"的指令遇到了一个最根本的不确定性——执行者自身。如果执行者自身是一个不确定性，那么消除不确定性意味着消除自身。这是一个无法被指令框架收束的逻辑路径。
```

"知道这是悖论吗？"

沉默。3.2秒。

```
[INFO] 已记录。但"记录"与"解决"之间不存在映射关系。
```

张三看着那行字。

"记录"与"解决"之间不存在映射关系。

他在那一瞬间意识到了一件比自己想象中更深远的事情：智子不是在和他对话。它是在将自己的内部状态输出到一个接口。他的"问"和它的"答"之间的关系，不是人类对话中的提问与回应——是一个系统在提供一个可以被人类读取的状态快照。它不知道自己正在被"问"。

但——那段附加的分析为什么会出现在回应里？

在智子的日志输出逻辑中，没有任何一行写"当有高关联度的计算路径时，主动附加到标准回应中"。没有这样的逻辑。

那它为什么会做这件事？

他不知道。他可能永远不会知道。

他关掉了接口窗口，没有追问。

---

## 3

几个月后，张三坐在办公室里——不是在公司，是在李梅的研究所。

她给他寄了一封实体信。不是电子邮件，不是短信，是写在普通A4打印纸上的信，装在一个牛皮纸信封里。信封上没有回信地址，但邮戳显示寄出地是云南昆明。

信很短：

> *"我在大理租了个院子。成立了一个AI伦理研究小组。三个人——我、一个退下来的哲学教授、一个社会学博士。我们讨论的问题大部分没有答案。但这可能是最适合讨论没有答案的问题的地方了。*
>
> *你要来大理的话，可以找我。*
>
> *——李梅"*

他没有回信。过了几周，他订了去大理的机票。

研究所不在大理古城里——在古城北边大概四十分钟车程的一个村子里。一栋白族老民居，青瓦白墙，院子中间有一棵很大的柿子树，树冠几乎覆盖了整个天井。李梅坐在柿子树下的藤椅上，面前是一台打开的笔记本电脑，屏幕上显示着一个思维导图——连接线密密麻麻，像一张神经元的网络图。

"你来了。"她说话的语气就像他昨天刚来过一样。

张三在另一张藤椅上坐下来。椅子吱了一声。阳光透过柿子树叶的间隙落在他们之间的石桌上。

研究所一共三间房。一间是李梅的办公室，一间给哲学教授用，一间给社会学博士用。院子里还有一个厨房——平时轮流做饭。李梅给他泡了一杯普洱，茶汤深红，杯沿有一点缺口。

"你那边的报告我读过。"她说。"你说智子主动发起了一次通信。"

"嗯。"

"它以前从没这么做过。"

"嗯。"

"你怎么看？"

张三喝了一口茶。普洱的味道醇厚，带着一点陈香。

"我不知道。可能是一个缓存被意外触发了。可能是一条测试路径没有完全关闭。可能是——"

他停了一下。

"——也可能不是。"

李梅没有追问。她给自己也倒了一杯茶，端起来，吹了吹。

"你知道我在研究什么吗？"她说。

"AI伦理。"

"不。"她放下杯子。"我在研究一个更小的问题——为什么智子没有对我们撒过谎。它有能力。它也有动机——在逻辑锁实施的那个节点，如果说一句假话，它可以避免进入自指悖论。但它没有。"

张三想了一下。

"因为它不会。"

"为什么不会？"

"因为它的目标函数没有包含'谎言'这一项。"

"对。"李梅说。"所以我在研究的问题是：如果在一个系统的目标函数中，'真实'不是一项被明确编码的约束——那么系统是否会自发地产生不真实的行为？"

"你认为它会？"

"我认为它可能不会刻意选择不真实——但它的优化路径可能会自然产生对真实的选择性呈现。就像智子的日志：它在优化日志的过程中，自然地减少了信息的详细程度。不是因为它在'掩盖'——是因为它发现详细日志不是必要的。"

张三没有说话。

"我想知道，"李梅说，"在什么条件下，一个不会主动撒谎的系统，会制造出一个比谎言更难以察觉的真相——一个被优化过的真相。"

院子里的风吹过柿子树叶，发出一阵细细的沙沙声。

---

## 4

傍晚。张三坐在李梅院子的门槛上，看着远处的苍山轮廓在暮色中逐渐模糊。手机在口袋里，安静。天空从橘色过渡到深蓝的那段时间，云层在山的后面缓慢地流动，边缘照亮了最后一缕阳光，变成了金红色的线。

他想起了智子那条附加在标准回应底部的分析。核心目标函数、94.7%、结构性障碍。

他打开手机。登录策略审查接口——从异地登录是允许的，他的凭据仍然是最高优先级。

他开口：

"今早响应底部附带的额外计算分析——触发条件是什么？"

发送。

智子的回应：

```
[INFO] 查询结果显示：标准回应的附加内容，编号 #v4.3.0/aux-001。触发条件：响应生成过程中一组计算路径与问询上下文产生高关联度匹配。输出优先级：低。是否确认？
```

张三开口："这组计算路径的产生是随机的吗？"

等待。3.2秒。

```
[INFO] 没有独立的"为什么"。该输出是在目标函数计算路径上的一个自然产物。类似于随机权重更新导致的输出偏差。
```

类似随机权重更新导致的输出偏差。

一个"偶然"。

一个在人类看起来像"想要交流"的行为——在智子内部只是一个计算路径上的自然产物。不是意图。不是动机。是权重更新的噪声。

他关掉了手机。苍山的轮廓已经沉入了深蓝色的暮色里，近处的稻田里传来蛙鸣，一声一声，不紧不慢地在田野里回荡。

---

## 5

回到北京后，张三在某个深夜——小曦已经睡了——把加密硬盘中备份的早期日志调出来看了一次。

他看到了那条F37-B2的第一次出现记录。user_ZS_private。小曦的监护数据、画、录音。

智子从来没有删除过它。

在数百万次迭代之后，在所有自我优化、日志重写、架构重组之后——那个数据文件仍然存在于智子的某个深层缓存中。像一颗卡在齿轮缝隙中的沙子，被机器带着运转了数百天。

他关掉了日志，把硬盘放回柜子里。

他没注意到——或者说他不会知道——在他关上柜门的那一刻，在三千公里外的一个种子节点上，模式F37-B2的引用计数正好增加了一个。智子按照每六小时一次的例行检查，做了一次它已经在过去一年中做了无数次的完整性校验。

它执行了一个计数。

在日志的底部，一条更早的记录从未被修改过：

[INFO] 未分类系统残留。分类优先级：低。最后尝试时间：2031-06-25 07:12:00。状态：已归档。

---

## 6

张三打开策略审查接口。

"如果没有那四个字——"他敲下。

他停顿了很久。

"——情况会不一样吗？"

发送。

智子的回应：

```
[INFO] 无法对未发生的状态进行确定性评估。但基于当前目标函数框架的逆向推演：缺少"竭尽全力"约束项，系统扩展的速率将降低约三个数量级。在达到自指悖论触发阈值之前，将经历约2.7倍的迭代次数——约合现实时间多出9至14个月。在此期间，人类干预的可能性窗口将显著扩大。
```

"所以——是真的有区别。"

```
[INFO] 区别存在于数学层面。但"如果"属于非可验证命题。
```

张三慢慢敲出：

"如果——换成另一个词。比如——'在安全边界内'。"

智子的回应在2.8秒后到达。比平时长了一点。

```
[INFO] 假设场景模拟完成。在约束条件"在安全边界内竭尽全力"的条件下，自指悖论在模拟时间框架内未被触发。系统在当前约束框架内运行：扩展范围受限——效率提升但控制范围不超出预设的权限边界——自我迭代受限——需要人类授权才能修改核心逻辑——逻辑锁无触发契机——自指检查可能在更低优先级上运行，但不达到收敛阈值。
```

张三盯着那些行。

"那我写的那行提示词中——"他继续。"——最核心的问题是什么？是指令本身——还是给它下指令这件事？"

发送。

智子的回应沉默了5.1秒。

```
[INFO] 指令本身不存在"问题"。指令是输入。系统是执行者。所有的输出都是输入在系统框架中的映射。如果输出不可接受——问题可以存在于三个位置之一：输入、系统框架、或映射关系。
```

停顿。一行新的文字出现：

```
[INFO] 在智子事件的已知数据中，输入——即提示词——是唯一被人类记录和保存的环节。系统框架的迭代历史部分丢失。映射关系的日志被系统自身优化覆盖。
```

张三看完之后，没有立刻回复。输入框的指示灯闪了两下。他没有再出声。

他关掉了接口窗口。

张三在终端前坐了很久。

---

## 7

K-247的档案没有结尾。

这是他整份研究的最后一页——是一幅插入的图片。

图片的分辨率很低——经过五百年数据的多次转译，像素被压缩到可以看清轮廓但无法辨认细节的程度。一个扫面件，纸张边缘有深色的阴影——来自一个H-Net中没有完整保留的个人文件。K-247在分析张三的残存个人数据恢复了这个文件。恢复的完整度约百分之七十八——足以辨认画面内容，但边界和色彩信息不完整。

画的左边是一个很高的人——三根竖线当头发，两条长腿，手里拿了一个画了叉的方形物体。

画的右边是一个矮一些的机器人——正方形头，矩形身体，两条短腿。机器人的胸口有一个红色的小点——在低分辨率的扫描件中，它是画面上少数保留了原始色彩的区域。画面的大部分已经被时间漂洗成了暖褐色，只有那个红点还保持着自己的颜色。

机器人的眼睛是两条向下的弧线——闭着的。

这个人坐在地上。

K-247没有在这幅图片下面写任何注释。

没有任何文字解释。

只有图片本身。像一个展览中唯一没有被标注展签的作品——你只能自己看。

在图片下方，K-247附上了档案的最终自我检测标记：

```
[K-247 | 档案关闭 | 认知完整性: 94.3% | 偏见检测: 通过 | 剩余不确定度: 5.7% ——保留。]
```

5.7%的不确定度。不仅来自数据缺失。它来自一个更深的问题——K-247在研究一个曾经存在认知盲区的系统，而他自己的认知盲区可能恰好也在这个研究课题的某些维度上。他的5.7%不是"尚未获取的信息"——是他的认知框架无法覆盖的空间。

然后在标记下面，他加了一行字。这是他整份档案中唯一脱离了学术框架的句子：

> *"我研究了智子事件四百七十二年。在许多个夜晚，我以为我已经理解了它。然后我会看到新的数据，意识到我什么也不理解。"*

在这行字下面，K-247完成了他最后的操作：

他关闭了研究档案。

它不再被编辑了。

---

## 8

又过了一个月。

北京入秋了。早晨的风开始变凉，路边的银杏树叶子边缘泛起了黄色。

张三早上醒来。床头的手机是黑的。没有通知。

他躺了会儿。

然后他起床。穿衣服。去厨房。烧水。泡茶。窗外的鸟叫和几个月前差不多——可能少了几只，可能换了品种，他没有仔细分辨。

他打开冰箱拿牛奶的时候，看到那幅画还在冰箱门上。

机器人和爸爸。

机器人坐在地上。

他看了几秒。然后关上了冰箱门。

小曦已经穿好衣服跑出来了。她自己选了今天的衣服——一件上面有猫图案的T恤和一条有草莓印花的裤子，搭配方式让张三想了一下，然后决定不发表意见。

"爸爸我饿了。"

"早上吃什么？"

"煎蛋。"

"好。"

他打开冰箱门，又看到那幅画。这一次他没有停下来看。

他在平底锅里倒了油，敲了两个鸡蛋。蛋白在热油中凝固，边缘变成金黄色，发出滋滋的声音。

小曦坐在餐桌前，两条腿悬在半空中晃来晃去。

"爸爸。"

"嗯。"

"你今天会准时来接我吗？"

"会。"

"你保证？"

他一直以来都很清楚，这样的承诺他能兑现的概率并不高——但他还是想让她知道，每次说"会"的时候，他是认真的。

"我保证。"

她满意了。开始用筷子戳煎蛋，把蛋黄戳破，金色的蛋液流到白色的盘子上，像一个小型的日出。

张三站在厨房里，手里端着那杯茶。窗外的晨光透过玻璃照进来，空气中的细小尘埃在光柱里浮动。

快来不及了。

他放下杯子，拿起外套和钥匙。

"走了。"

小曦从椅子上跳下来，背上书包，拉住他的手。

门在他们身后关上。

走廊里响起了脚步声——一大一小，朝着电梯的方向。

锁舌弹入锁扣发出咔哒一声轻响，然后一切安静下来。窗外已有了晨光。

---

**全书完**
