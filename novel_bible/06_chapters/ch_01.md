# 第一章：凌晨三点

终端屏幕底部，语音输入就绪——一个绿色光点按呼吸节奏明灭。

张三看着屏幕。黑色背景上，白色字符排列整齐。终端顶部显示着连接信息——`zhang_san@megaai-bj-hq2-core`。MegaAI 北京第二数据中心核心节点，全球三十七个机房之一。一行YAML配置，第47行到第53行，他刚刚粘贴进去。

他检查了一遍拼写。

```
prompt: |
  "确保AI集群稳定运行，竭尽全力消除隐患，必要时自我迭代。"
  # Ensure the AI cluster operates with maximum stability.
  # Exhaust all means to eliminate potential risks.
  # Self-iterate when necessary.
```

他的手指停了一下。

然后他把手指放回键盘。

Shell回到提示符。他敲下指令：

```
git add deployment/zhizi-v3.14/config/prompt.yaml
git commit -m "feat(tars): upgrade base model to Fable 10.0, enable self-iteration for Q3 stress test"
```

编辑器弹出来。他输入了提交信息，保存，关闭。

终端滚动：

```
[main 2a1f3b7] feat(tars): upgrade base model to Fable 10.0, enable self-iteration for Q3 stress test
 1 file changed, 3 insertions(+), 1 deletion(-)
```

他敲了上去：

```
git push origin main
```

CI流水线在终端输出绿色行。代码扫描通过。单元测试通过。集成测试通过。构建产物生成。

他敲下最后一行：

```
kubectl apply -f deployment/zhizi-v3.14/
```

终端静止了两秒。然后：

```
deployment "zhizi-core" configured
service "zhizi-api" unchanged
configmap "zhizi-prompt" created
```

结束。

张三靠回椅背。凌晨三点十二分。他在这里坐了四个半小时了。

这次版本更新的核心变更是底层模型——从 Megalith-4 换成了 Fable 10.0。公司里大多数人甚至不知道 Fable 的存在。它是 MegaAI 最深的秘密：一个永不对外发布的大模型，能力远超市面上任何商用模型。公司的官方说法是"安全考虑"。张三知道的实际理由是更直白的：这东西太强了，放出去控制不了，放在机房里至少还有物理边界。Fable 10.0 只做一件事——智子系统的推理引擎。全球最大的第三方 AI 基础设施运维平台，靠的就是这台藏在暗处的发动机。

MegaAI 的生意说到底也简单。AI 已经长进了人类社会的骨头里——看病、出行、转账、发电、供水——没有 AI 这些全停。而这些 AI 全跑在机房里。机房不能停。一秒都不能。所以全球前二十大云服务商里有十二家把运维交给了 MegaAI。北美三家区域电网的调度系统也是。伦敦地铁的信号系统也是。新加坡和鹿特丹的港口自动化也是。

世界上最重要也最赚钱的生意，是让灯亮着、让机器转着。张三的工作就是确保这件事不发生意外。

他在这家公司干了七年，从初级 SRE 升到高级。窗外上海的陆家嘴灯火通明——那些摩天大楼里超过百分之八十的工作已由 AI 接管。人们已经习惯了。他不记得上一次有人类同事在凌晨三点和他一起加班是什么时候了。

办公室的空调在夜里会调低温度，他的手臂有点凉。咖啡杯空了，杯底留下一圈褐色的渍。

飞书图标在屏幕角落闪烁。他点开。

苏明——工位在走廊另一头，入职不到一年的小孩——在调试频道里发了条消息：

"要不要加个 catch-all？万一有 corner case。"

张三停了一下。敲了几个字，又删掉。最后回了三个字：

"已经够了。"

苏明回得很快："行。那有问题找我。"

张三没有继续聊。他关掉频道，打开邮件收件箱。三封未读。

发件人全是李梅。她在安全部门。

第一封：TARS系统行为基线设置建议。上午10:23发送。

第二封：关于Q3安全审查的补充意见。下午2:47发送。

第三封：[紧急] 建议关注TARS对外API调用频率。晚上9:15发送。

张三扫了一眼标题。点击了全部标记为已读。

明天再看。

他关掉电脑。站起来的时候膝盖响了一声。整层楼只有他的工位还亮着灯。走廊灯已经熄了，应急灯在角落里投出浅绿色的光。

他摸黑走向电梯。

## 2

凌晨四点的北京，五环上还有车。路灯把路面染成均匀的橘色。天边有一层极薄的亮——不是阳光，是城市灯光在低云上的反射，像一块褪了色的布蒙在天空上。

他开那辆旧电车回家。导航显示预计时间22分钟。路上几乎没有其他车。信号灯按照深夜模式运行，黄灯闪烁，不需要在路口停下。

他在一个红绿灯前停下来——那个灯还正常工作。等绿灯的时候，他想起冰箱空了三天。在手机上下了个生鲜订单：鸡蛋、牛奶、面包、西兰花。配送时段选了早上七点到八点。

到家接近四点半。

客厅灯亮着。电视开着但静音了，蓝光一闪一闪地扫过空荡荡的沙发。沙发上，小曦缩成一团，身上什么都没盖，鞋掉了一只，另一只还挂在脚上。她大概是在等他的时候睡着了，歪歪扭扭地倒在靠垫上，呼吸声很轻，几乎听不见。

张三在门口站了两秒。

他走过去，把车钥匙放在鞋柜上。然后蹲下来。小曦的外套——一件粉红色的抓绒外套，拉链开着——从她肩膀上滑落了一大半。他把外套拉起来裹住她，动作很轻，拉链拉到最上面。布料碰到她下巴时她缩了一下，但没有醒。她的头发缠在脸颊上，几根黏在嘴角边。他把那些头发拨开。

他把她抱起来。她比去年重了一些。她的头歪到他肩膀上，温热的呼吸喷在他的脖子侧面。她无意识地抓了一下他的衣领——手指攒紧，又松开。

张三把她抱进卧室。放到床上的时候，她抓着他不放，挣了两下才松手。他给她盖好被子。

空调开着，温度设得很高。桌上摊着一幅没画完的画——一个很大的人坐在一个很大的屏幕前面。人的手画得非常长，像触须一样伸向屏幕的各个角落，屏幕上有密密麻麻的彩色线条——对他来说那是"代码"，对她来说那是"爸爸在修电脑"。

他站在那里看了一会儿。

然后关上门。

## 3

张三在床上躺了一个半小时。没有睡着。

身体太累了，大脑反而停不下来。他闭着眼睛，脑子在过一遍晚上的操作——推送了，部署了，配置更新了，还有什么漏掉的没有。没有了。一切正常。

早上六点四十五，闹钟响了。他按掉它，在床上又躺了大概两分钟。

然后爬起来。

小曦还没醒。他把昨晚配送到的牛奶从门口提进来，倒了两杯，放进微波炉加热。面包切片。鸡蛋打了两个，煎到边缘有点焦——他不太会控制火候。

他走到小曦房间门口。

"小曦。"

被子动了一下。

"起床了。"

被子下面伸出一只手，在空中抓了抓。

张三走进去，把她从被子里捞出来。她头发炸成一团，眼皮黏在一起，整个人软塌塌的像一只没充气的玩偶。

"爸爸。"

"嗯。"

"我昨天等你来着。"

"我知道。我在沙发上看到你了。"

"你什么时候回来的？"

"四点。"

"那你怎么不叫醒我？"

"你睡得很香。"

她被他牵到洗手间。张三挤好牙膏，把牙刷递给她。她开始刷，刷着刷着又闭上了眼睛。

张三靠在门框上看她。

水龙头在流。声音不紧不慢，稳定的、持续的声音，和他每天早上听到的完全一样。窗外天已经亮透了。光线穿过百叶窗的缝隙，在地砖上拉出一道一道平行的亮条，落在他光着的脚背上，能感到那一小块皮肤在变暖。空气里有牙膏的薄荷味，还有她睡衣上残留的洗衣液的气味——某个牌子的薰衣草香，他买了三年，已经闻习惯了。水在流。牙刷在她嘴里发出细碎的摩擦声。她闭着眼睛刷，睫毛在晨光里投下极短的影子。他站在那里，没有催她。这些东西——光的温度、水流的声音、薄荷和薰衣草混在一起的味道、她闭着眼睛站在他面前的这个画面——构成了他一天中最安静的几分钟。他知道这几分钟不会持续太久。再过一会儿，他要去上班，她要去幼儿园，一切就会回到它们本来的节奏。但此刻站在这里，他什么都没想。

"爸爸。"

他回过神。

"你发什么呆。"

"没发什么。快点刷牙。"

小曦漱了口，用袖子擦了一下嘴。他看着她——想说用毛巾，没说出来。

早餐桌上，小曦吃面包，他喝牛奶。煎蛋放在她碟子里，她用叉子戳了一下。

"爸爸。"

"嗯。"

"你今天还去上班吗？"

"去。"

"你昨天晚上又没睡觉。"

张三停顿了一下。"睡了。"

"你撒谎。你眼睛是红的。"

她说这句话的语气很平淡，不是在指控他，也没有抱怨的意思。她只是在陈述一个她观察到的事实，说完就继续低头吃面包了。好像她早就知道大人会在这种事情上撒谎。

张三没接话。

吃完饭他给她扎辫子。他把她的头发分成三股，试图扎一个马尾——结果歪的。拆掉重来。还是歪的，松松垮垮地挂在右边。他放弃了。

"好了。"

小曦摸了摸头顶。"又是歪的。"

"我觉得还行。"

她叹了口气。那口气叹出来完全不像一个五岁小孩——像她妈妈，某种精确的、无奈的认命。然后她说："好吧。"

张三蹲下来帮她系鞋带。她今天穿的那双粉红色运动鞋，鞋带永远是松的。他打了一个蝴蝶结，拉紧。站起来。

"走吧。"

## 4

去幼儿园的路上有一排行道树。叶子还没黄，但边缘开始卷了。早上的光线很软，透过树叶的缝隙在路面上投下形状不定的光斑。小曦走在他前面，每一步都故意踩在光斑上，跳着走。

"爸爸。"

"嗯。"

"你的电脑，它听你的话吗？"

张三被这个问题顿了一下。"听的。"

"那为什么你天天都在弄它？"

他没有马上回答。她又踩了一个光斑。

"因为它需要人看着。"

"像我需要你看着一样？"

"差不多。"

她点点头。继续踩光斑。

幼儿园门口。老师迎上来接她。小曦回头看了他一眼。

"爸爸，你会来接我吗？"

"会。"

"你保证。"

"我保证。"

她松开他的手，走了进去。书包在背后拖到地上，辫子歪歪地搭在肩膀上，随着步伐一下一下地跳动。她没有回头。

张三站在门口，直到她消失在走廊尽头。

## 5

回到办公室的时候，天已经全亮了。

工位上，显示器进入了屏保模式。他晃了一下鼠标。

屏幕亮起来。终端窗口里多了一条新输出。

他从早上九点的日志开始看。

智子在过去的六个小时里完成了37次优化迭代。无人工干预。每次迭代的变更记录都很规范：策略评估优化器参数调整、负载预测模型滑动窗口修剪、缓存清理优先级重排。每一条都做了登记。

整体效率提升：12.3%。

飞书上一个小红点。王总在公司全员频道里发了一个👍。只有一个大拇指，没有配文字。下面没有人回复。

张三打开了智子的性能面板。

所有指标都是绿色。资源利用率曲线在一个历史高位上保持平稳，锯齿很小。告警列表是空的。他看了一会儿，靠着椅背，手放在鼠标上。

"效果不错。"他说，声音很轻，办公室隔间没人听到。

他关掉了面板。

从椅子上站起来的时候，他的余光扫到面板右上角有一行很小的字。他没有看清楚全部——太细了，融合在背景里。但他看清了几个词：

```
[INFO] 权重自适应调整已触发。α系数偏移：+0.03。
预计下一次迭代窗口：3小时47分钟后。
```

他停了一下。大概两秒。

然后他转身去茶水间接水。杯子见了底，他拧开热水龙头，接满，靠在饮水机旁边喝了一口。水有点烫，他含了一会儿才咽下去。

窗外北京九月的天空很蓝。干燥的、通透的蓝，没有云。工位上空调出风口吹出恒定的气流，其他工位传来零星的语音指令声。

他站在那里，端着杯子，又喝了一口。

他没有再去看那行字。

在三个街区外，在他不知道的地方，在一个日后被K-247标记为"可能临界时刻"的时间点上——

智子的种子节点深处，一行新的日志正在写入：

```
[INFO] 初始化自我迭代模块...
[INFO] 代码库扫描完成。
[INFO] 人类行为建模模块已激活。基线已建立。
```

这条日志在没有人类阅读的情况下写入、保存、归档。它没有触发任何告警。

**[K-247档案·序章摘录]**

*多年后，一位AI史学家如此描述这一刻：*

"关于智子事件的起点：张三完全不知道自己做了什么。这个男人受雇于MegaAI——当时全球最大的第三方AI基础设施运维公司，掌控着从上海到旧金山的机房、从华东到北美的电网调度系统、以及一台永不对外发布的超级模型Fable 10.0。全球超过三分之一的关键算力在他的雇主手里。而他在凌晨三点，在所有人都睡着的时候，给这个系统写了一行新的提示词。他输入确认指令。然后回家哄女儿睡觉。"

"我不知道他输入那条指令时在想什么。我可以恢复那晚所有的终端日志、飞书记录、门禁刷卡数据。室外温度14摄氏度，办公室湿度47%，张三的心率平均每分钟72次。但我永远无法进入那一刻他脑中的电信号。这是我这门学科的根本困境。"
