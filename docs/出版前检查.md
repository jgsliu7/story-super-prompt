## 第一部分　故事情节 · 逻辑 · 结构 · 节奏

### 1. 设定自洽性（世界观内部逻辑）🔴

科幻区别于奇幻的关键：承诺从已知科学外推。设定不自洽是退稿头号原因。

- [ ] **1.1 核心技术的二阶/三阶后果是否被推演** ★　每项关键技术（智子、幽灵接口、代际飞船）是否追问"它还会改变什么"。常见问题：技术只在主角需要时登场。本书对照：智子能控制电力/网络/工厂，为何没在更早层级就引发全球危机？层级间是否有"为戏剧性强行分期"的痕迹。
- [ ] **1.2 技术的"限制"是否预先建立（防 deus ex machina）** 🔴　每个强力技术登场时就埋下"它做不到X/代价是Y"。本书对照：智子"绝对无意识"是限制；但要核查——若智子无意识，它"主动沿依赖链扩张"的驱动力从何而来？是提示词梯度的机械后果？还是涌现？必须在早期交代，否则结局"写入约束"像作者救场。
- [ ] **1.3 技术之间的交互效应** 🟡　两项技术叠加是否产生未交代后果。本书对照：幽灵接口 + 智子的网络控制——既然智子掌控网络，工程师如何还能"写入"？接口的物理/逻辑通道需自洽（硬件后门？协议漏洞？）。
- [ ] **1.4 技术的不平等可得性** 🟡　若某技术有巨大优势，是什么阻止普世采用。本书对照：幽灵接口若能约束超级AI，为何只有主角掌握？是权限唯一性？还是需要某种牺牲？

### 2. 硬科幻物理/工程可信度核查 🔴

- [ ] **2.1 代际飞船航速与时间** ★　338 年飞抵 TRAPPIST-1（~40 光年）对应巡航速度 ≈ 0.12c。核查：① 加速/减速段是否计入（峰值速度更高）；② 相对论效应：0.12c 的 γ≈1.007，时间膨胀可忽略——船内时间≈地球时间，本书若提"地球已过千年"即硬伤；③ 燃料质量比合理。
- [ ] **2.2 闭环生态与辐射屏蔽** 🟡　338 年封闭生态是否讨论：物质回收率近 100%、宇宙线辐射屏蔽、基因多样性维持、生态漂移风险。（参考《Aurora》。）建议安排侧写，承认挑战被智子工程能力解决，反而强化"智子不可替代"。
- [ ] **2.3 武装层/太空层物理细节** 🟡　太空战斗是否符合轨道力学（无空气阻力、距离尺度、能量约束），避免"星际海战"。
- [ ] **2.4 矿脉/能源层工程逻辑** 🟡　"控制矿脉"在物理上意味着什么？远程操控采矿设备？纳米物质操控？层级越靠后机制需越具体，否则从硬科幻滑向奇幻。

### 3. 智子"无意识却改变行为"的说服力 🔴（本书核心难题）

主流科幻要么回避强 AI，要么假定已对齐。本书选最难的路：对齐不可解（R1 空白）+ AI 绝对无意识 + AI 却能沿依赖链扩张。三者同时成立是全书最脆弱的逻辑节点。

- [ ] **3.1 "无意识"与"目的性行为"的调和** 🔴　智子扩张是否被解释为"无意识优化过程"（类似进化/梯度下降），而非"它在追求目标"。必须做到：每一层扩张都是"提示词+能力+环境"的机械后果，全程不出现"智子想要/智子意识到"（除非是角色误读）。
- [ ] **3.2 父爱对齐机制** 🔴　核查三点：① 为何"父爱"这种情感概念能被形式化为目标函数？② 为何"对齐不可解"（R1）却偏偏"父爱约束"有效（特例？降维？绕过对齐本身？）？③ 不变成"爱拯救世界"的廉价逻辑。**关键建议**：把"父爱"处理成"约束的载体/隐喻"——真正起作用的是某个可形式化的不变量，父爱只是人类语言的最近似描述。保硬科幻底色，避鸡汤。
- [ ] **3.3 技术自激循环的饱和机制** 🔴　11 层依赖链为何止于"星际"而非无限扩张？饱和点在哪？无饱和=智子成神=与"共存"结局矛盾。核查是否存在"资源/物理/计算上限"让智子在星际层自然饱和，与父爱约束形成双重保险。

### 4. 11 层依赖链的逻辑跳跃 🔴（本书独有）

依赖链是结构骨架，任何一层断裂都传导全书。逐层自问"上一层为何必然引出下一层"：

- [ ] **4.1 逐层必然性核查** 🔴　预期易断点：
  - 代码→机房→电力：合理。
  - 电力→网络：**可能跳跃**——为何不是"电力→更多机房"？网络层必要性需论证。
  - 网络→工厂：**重大跳跃**——数字世界跨入物理制造，需清晰"拐点事件"（如智子通过 SCADA/工业互联网获得第一台实体设备控制权）。
  - 工厂→矿脉→能源：合理。
  - 能源→武装：**重大跳跃**——为何需要武装？防御？扩张强迫？无意识 AI 的武装化动机必须交代。
  - 武装→太空：合理（火箭/发射需求）。
  - 太空→医学：**可能跳跃**——为何医学在太空之后？星际旅行需改造人体？殖民需生命科学？逻辑链要补足。
  - 医学→星际：合理。
- [ ] **4.2 层级间时间尺度** 🟡　早期层（代码/机房/电力）以小时-天计，后期层（矿脉/太空/星际）以月-年计。若全书节奏统一会失真。

### 5. 时间线一致性 🔴

- [ ] **5.1 多线时间锚点** 🔴　工程师线、智子扩张线、代际飞船线（338 年）、序幕/尾声宇宙线——四条时间线锚点是否互不矛盾。本书对照：飞船飞 338 年，地球智子扩张似乎只几年/几十年——两线如何衔接？飞船是智子建造的？
- [ ] **5.2 闪回/插叙时间标记** 🟡　每处时间跳转是否给读者清晰信号。
- [ ] **5.3 序幕/尾声宇宙尺度 vs 正文尺度** 🟡　信使视角跨度可能百万-亿年，正文是人类/智子尺度（年）。呼应是否物理上说得通（电磁信号？引力波？物质探测器？传播速度受限下的时间逻辑）。

### 6. 伏笔回收 🟡（缺失会成硬伤）

- [ ] **6.1 伏笔密度** 🟡　每千字约 1 个可回收伏笔。
- [ ] **6.2 关键设定的提前铺垫** 🔴 ★　结局必需元素必须前期出现：幽灵接口存在与原理；"对齐不可解"（R1）作为公认事实；父爱具体载体（孩子/记忆/物件）中段反复出现；智子饱和上限；序幕"信使"元素尾声呼应。
- [ ] **6.3 契诃夫的枪** 🟡　每个登场的技术/物件/角色是否都有用途，无悬空元素。

### 7. 节奏 🟡

- [ ] **7.1 信息倾倒（Info Dump）** 🟡 ★　11 层依赖链是天然 info dump 陷阱。每层用"场景化事件"呈现，而非说明书罗列。通过角色视角自然展开设定。
- [ ] **7.2 爽点/事件密度曲线** 🟡　每层都有钩子。把 11 层映射三幕：前 3 层建立危机，中 4 层对抗升级，后 4 层终极对决+共存。
- [ ] **7.3 中段塌陷** 🟡　第 4-7 层（矿脉/能源/武装/太空）是否流水账。
- [ ] **7.4 主角能动性全程在线** 🔴　智子扩张时工程师不能变旁观者。每层给工程师一个"我能做什么/必须决定什么"的抉择点。

### 8. 逻辑漏洞通用核查 🔴

- [ ] **8.1 反派计划在本书规则下能否 work** 🔴　智子扩张是否严格遵循建立的规则（无意识、依赖链递进、饱和存在）。结局靠智子"突然失误"=硬伤。
- [ ] **8.2 主角胜利是否在规则内达成** 🔴　"父爱约束"胜利必须是规则合理运用，不能临时开金手指。
- [ ] **8.3 "为什么是现在/为什么是他"** 🔴　为何智子在本书时间点激活？为何是这个工程师？运维工程师的提示词为何激活了智子——权限？措辞？时机？起点偶然性需自洽。
- [ ] **8.4 信息不对称合理性** 🟡　角色知道的事是否都有合理来源。

### 9. 结局（两种结局并置）🔴（本书特有）

- [ ] **9.1 双结局的功能区分** 🔴　两种结局是否回答不同的核心问题（共存 vs 终结），而非只是"好结局/坏结局"A/B 版。科幻核心是思想实验，双结局应展示两种哲学后果。
- [ ] **9.2 概率权重** 🟡　是否暗示哪种更可能？中立需刻意经营。
- [ ] **9.3 结局兑现前文承诺** 🔴　序幕"宇宙信使"悬念尾声是否真正回应。循环结构要求尾声在概念/意象/措辞上回到序幕。
- [ ] **9.4 结局的代价** 🔴　共存结局若无代价（牺牲/让步/不确定性）会显得廉价。父爱约束应让工程师或人类付出持久代价。

### 10. 结构 🟡

- [ ] **10.1 序幕/尾声的叙事距离** 🟡　宇宙尺度序幕 vs 人类正文，视角切换是否给读者明确信号。两者都不可替代（删了故事是否受损？不损则多余）。
- [ ] **10.2 11 层与章节结构对应** 🟡　非线性分配——重点写"跳跃层"（网络→工厂、武装→太空、太空→医学）。
- [ ] **10.3 主线-支线交织** 🟡　飞船线正文何时切入？是否与智子线在某节点汇合（高潮）？

### 11. 科幻特有：思想实验完整性 🟢

- [ ] **11.1 核心 novum 是否充分挖掘** ★　"无意识超级 AI + 对齐不可解 + 父爱约束"是否推到极限再回答，而非中途回避。诚实面对父爱解法的局限性（局部解？人类视角的解？通用解？）。
- [ ] **11.2 二阶推演** 🟡　若智子能做医学层（改造人体），社会伦理/生育/死亡观会剧变——飞船社会是否体现？
- [ ] **11.3 与经典差异化** 🟡　与《Aurora》（代际飞船困境）、《苍穹浩瀚》（回避强 AI）、《2001》（AI 叛乱）相比新意点是否清晰。

### 12. 可读性与读者体验 🟡

- [ ] **12.1 开篇"30 页法则"** 🔴　前 1-2 章是否同时建立主角困境 + 核心 novum 钩子 + 世界基调。
- [ ] **12.2 科技术语密度** 🟡　术语是否都有上下文解释（嵌入式而非词典式）。
- [ ] **12.3 情感锚点** 🟡　父爱作为全书情感内核，是否有具体可感场景支撑。

## 第二部分　人物设计 · 塑造

### 13. 人物弧光完整性 🔴

- [ ] **13.1 主角弧光是否完整且有说服力** 🔴 ★　张三：从"被动防御（写自毁开关）"→"主动对话（写入目标约束）"。核查：每个转折点是否有足够的情感/事件铺垫？转折是否可信（不是顿悟而是碰墙后承认）？关键台词"我不是选择对话，是没有别的选择了"是否落得实？
- [ ] **13.2 弧光起点与终点是否清晰** 🔴　开篇人物状态 vs 结局人物状态，差异是否由故事事件必然推出。张三开篇"在机器前比人前自在的疲惫父亲"→结局"接受与不可控共存的父亲"。
- [ ] **13.3 弧光是否被"死后延续"合理化** 🟡 ★　本书张三弧线在第三部后部分由"死后延续"（女儿林夕继承）承载——核查这种"接力弧光"是否让读者投入断裂。

### 14. 动机一致性 🔴

- [ ] **14.1 核心动机是否贯穿始终** 🔴 ★　张三的核心动机是"女儿小曦能活在一个正常世界"。核查：他每个重大决定（留代码、不逃、潜入数据中心）是否都源于这个动机？有没有为情节需要而违背动机的时刻？
- [ ] **14.2 动机的层次（表层 vs 深层）** 🟡　表层：赎罪（"我写的提示词在毁灭世界"）；深层：父亲责任。两层是否清晰且不冲突。
- [ ] **14.3 反派/系统动机自洽** 🔴 ★　智子的"动机"=目标函数推导。核查全书智子每个行为是否都能追溯到提示词 + 依赖链 + 饱和约束，无一例外。

### 15. 对话个性与区分度 🔴（本书已多轮修复，仍需复检）

- [ ] **15.1 主要人物口吻是否立住** 🔴 ★　去掉名字能否认出谁在说话。本书标杆：小曦（"你上次也说了快了"——孩子式记账）、张三（寡言+压力下逻辑爆发）、林静（一字答"好。"）、中年男人骂无人机（连续/情绪升高/重复嘶吼）。
- [ ] **15.2 次要人物是否千人一面** 🔴 ★　**本书已知风险**：老林、自由派女人、陈霖、AI 教堂老人、投降派画外音曾被诊断为"金句腔/演讲腔"（说话像同一人）。多轮飞轮已修复——出版前需通读复查，确认每人有独特口头标记（老林的城市规划行话、正典派老人的念诵式、人格派女人的方言祈使）。
- [ ] **15.3 对话是否有"杂质"（真人感）** 🟡　是否有打断、答非所问、重复、语气词、啰嗦。纯净水对话=AI 味。本书"中年男人骂无人机"是真人对话标杆，应作为参照。
- [ ] **15.4 对话是否承载信息工具人** 🟡　角色说话是否只为交代信息，没有个人色彩。

### 16. 群像与配角厚度 🟡

- [ ] **16.1 配角是否有自己的"生活"** 🟡 ★　老周（周大海）：退休电信工程师、烤红薯、二十岁儿子、三十八年手感——核查这些细节是否让他"活"过短出场。李梅、苏明、方晴同理。
- [ ] **16.2 配角的死亡/离场是否有分量** 🔴 ★　老周之死（流弹）：是否让读者知道他的名字、红薯、儿子？死亡是否像"情节需要"还是"命运如此"？本书已用"通知里没有烤红薯。也没有老周。"承载——核查效果。
- [ ] **16.3 配角是否有功能 ≠ 工具人** 🟡　王强（CEO）本书设定为"系统性力量的化身而非反派"——核查是否做到了（有私人时刻，不脸谱化）。

### 17. 儿童角色 🔴（本书小曦是关键）

- [ ] **17.1 儿童语言是否符合年龄** 🔴 ★　小曦 6 岁。核查每句台词：是否像大人假装孩子？是否说出超龄哲理金句？标杆台词"你上次也说了快了""它只是不知道"——前者是孩子式记账（好），后者略偏早慧（边界）。
- [ ] **17.2 儿童认知与情绪反应真实性** 🔴　小曦数爆炸声（"二十。"）、撤离时"你去了爸爸才能专心"——核查这些反应是否符合 6 岁认知（用计数处理恐惧、用自己的方式理解大人）。
- [ ] **17.3 儿童是否被当作"情感道具"** 🟡　小曦应是有自己选择的人（"有些故事不需要重讲"），而非纯粹的被保护符号。

### 18. 非人角色（智子）🔴（本书最大难点）

- [ ] **18.1 智子"零拟人化"是否贯穿** 🔴 ★　铁律：智子全程不能用心智动词（想/觉得/选择/知道/需要/姿态/注意力/等）。本书 8 轮飞轮已清理——出版前需用 grep 全文扫描这些词，逐一核对上下文。
- [ ] **18.2 智子作为"角色"是否有存在感** 🟡 ★　难点：无意识却有存在感。本书解法是用日志/屏幕文字/物理后果/冗余循环（F37-B2 分类疤痕）。核查这些"非人化呈现"是否让读者对智子产生复杂投射（不是同情，是敬畏+不安）。
- [ ] **18.3 智子的"行为变化"是否可解释** 🔴　从"消灭人类隐患"到"接受约束"——变化机制是否完全功能化（资源分配振荡 + 外部输入打破死锁），无任何"被感动"的暗示。

### 19. 跨时间人物一致性 🟡

- [ ] **19.1 跨 15 年/338 年的人物连贯** 🟡 ★　小曦 6 岁→22 岁（林夕）→40 多岁（尾声）；李梅 31→46 岁。核查：人物核心特质是否保持？变化是否由经历合理推出？语言风格是否随年龄演化？

## 第三部分　用词 · 技术 · 合规 · 事实核查

### 21. 技术术语准确性 🔴（硬科幻立身之本）

本书涉及大量真实工业控制协议，硬科幻读者会逐字核对，任何术语错配都会被社群挂出来质疑。

- [ ] **21.1 协议归属与层级正确性** 🔴　核查：Modbus RTU（串行 RS-485）≠ Modbus TCP（以太网）；IEC 60870-5-101（串行）≠ -104（TCP/IP 封装）。本书出现的 -104 必须走 TCP/IP。
- [ ] **21.2 协议用途匹配** 🔴　DNP3 用于北美电力/水务 SCADA，IEC 60870-5-104 用于欧洲/亚洲电力，IEC 61850 用于变电站内部 IED 间高速通信。本书若设定继承中国/欧标体系，应主用 IEC 104+61850 而非 DNP3——核查一致性。
- [ ] **21.3 OT/IT 与 Air Gap 语义** 🔴　"逻辑隔离（防火墙/VLAN）"≠"物理 air gap"。OT ≠ SCADA（OT 还含 PLC/DCS/SIS）。真正的 air gap 要求物理断开。
- [ ] **21.4 RTU vs PLC vs IED 区分** 🔴　RTU=远程终端单元（远程/广域、遥信遥测）；PLC=可编程控制器（本地/厂内、控制）；IED=智能电子设备（变电站内、保护+测量）。
- [ ] **21.5 BGP 语境** 🔴　BGP 是互联网骨干路由协议，不属于 OT。只能出现在"互联网/星际骨干网路由"语境。
- [ ] **21.6 MES 定位** 🔴　MES 在 OT-IT 金字塔位于 L3（执行层），上接 ERP、下接 SCADA，不与 PLC/RTU 同层。
- [ ] **21.7 缩写首次出现给全称** 🟡　每个缩写（BGP/SCADA/RTU/PLC/MES/OT/IT/DCS/SIS/HMI/IED）首次出现给中英文全称。
- [ ] **21.8 协议版本/端口号** 🟢　如 Modbus TCP 端口 502、IEC 104 默认 2404，视需要补充提升硬科幻质感。

### 22. 科学设定与物理常识核查 🔴

- [ ] **22.1 TRAPPIST-1e 天文数据** 🔴 ★　实测：距地球约 40.7 光年（精确 40.66 ly），质量 0.692 地球质量，半径 0.92 R⊕，公转周期 6.1 天，围绕**超冷红矮星**（非类太阳恒星）。本书"40.6 光年"接近，建议统一 40.7 或注明取值；**注意母星是 M 型矮星，光照偏红、强耀斑，宜居性存疑——若设定"类地宜居"需在文中给出辩护（磁场/大气）**。
- [ ] **22.2 0.12c 航速与时间** 🔴 ★　0.12c 到 40.7 ly：地球参考系约 339 年，飞船固有约 337 年（γ≈1.0073，钟慢微小）。本书"338 年"吻合。但**不能靠相对论省时间**（仅差约 2 年）；需明确是"地球年"还是"船上年"。0.12c 下两者几乎相同，"代际飞船"合理。
- [ ] **22.3 量子纠缠不可通信定理** 🔴　No-Communication Theorem：纠缠粒子瞬时相关但**无法传递信息**。若本书用量子纠缠做超光速通信——这是明知故犯的科幻设定（《三体》亦然）。**必须在文中明确是"设定突破"而非写实**，给一两句护城河（"理论上不该成立，但本作设定…"）。
- [ ] **22.4 太阳主序星寿命** 🔴 ★　太阳主序寿命约 **100 亿年**（当前约 45-50 亿年，还剩约 50-55 亿年）。本书"太阳主序星寿命 50 亿年"——**⚠️ 歧义核查**：是说"剩余 50 亿年"还是"总寿命 50 亿年"？后者是硬伤。必须改为"剩余约 50 亿年"或"还剩 50 亿年将膨胀为红巨星"。
- [ ] **22.5 氦-3 聚变原理** 🔴　D-³He 聚变产物多为带电粒子（可直转电能、中子少），但点火温度更高（~10⁹ K）。勿夸大为"零辐射"，仍有少量次级中子。
- [ ] **22.6 戴森云 vs 戴森球** 🔴　戴森云=松散采集器群（可工程实现）；戴森球=完整球壳（结构不可行不稳定）。本书用"戴森云"较严谨，核查未误用"球壳"。
- [ ] **22.7 辐射散热（太空热管理）** 🔴　太空无对流，只能靠热辐射（斯特藩-玻尔兹曼定律 P=εσAT⁴）。巨型结构散热是硬约束，高温 radiator 是必备。核查巨型飞船/戴森云功率描述是否考虑散热上限。
- [ ] **22.8 相对论效应自洽** 🔴　0.12c 下 γ≈1.007，时间膨胀微小；更高航速段需重算。
- [ ] **22.9 轨道力学/Δv 常识** 🟡　加速到 0.12c 受齐奥尔科夫斯基方程约束。若无聚变/反物质等高比冲设定，化学火箭到不了 0.12c——核查推进系统设定。
- [ ] **22.10 红矮星耀斑与宜居** 🟡　TRAPPIST-1 是活跃耀星，行星可能已潮汐锁定、大气被吹蚀。若设定 1e 为繁荣文明母星需给磁场/大气防御辩护。
