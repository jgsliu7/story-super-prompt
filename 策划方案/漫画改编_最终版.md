## 3. 四件必采装置（跨版合并，缺一不可）

### 3.1 提示词 ×3 同版式 + 光标镜像收束（V3 排印规范 + V4 变体 B）

三次同字体、同字号、同行断，一字一标点不动。三处三种介质：①人写的（屏底，句末光标闪）→ ②被念出来的（黑底无框）→ ③机器校的（黑底专色，无光标，多一行"校验通过"）。开头那页"还能改"，结尾这页"不能改了"——全书 150 页就是这两页之间付出的代价。条漫轨同款制度（V2 三介质版本：书写视角/声音视角/机器视角）。

### 3.2 刺点红制度（V3 全采）

四专色：纸白 / 石墨（冷黑）/ 屏青 / 双闪琥珀 + 刺点红（Pantone 485U）。**红全书限 25 格，只有四个户口**：未读消息红点、女儿小机器人充电灯、大屏告警曲线、摄像头红点。红点弧线：一章两个未读红点 → 三章告警曲线 → 九章充电灯 → **十一章红点熄灭（张三点开两条语音的那一格，全书情感落点）** → 十二章摄像头红点转半圈停住（全书最后一个红）。红=在等待的东西，红熄灭=不再等了。双闪琥珀与过马路的鸟同色——世界的暖色此后归谁，留给读者。

### 3.3 尺规吞噬手绘（V4 全采，逐话量化）

系统元素用尺规线、绝对对称、一点透视；人类元素用抖动手绘线、偏心构图。系统元素占画面比例逐话递增：15%→20%→30%→35%→40%→40%→55%→60%→65%→70%→75%→85%→90%→95%。读者说不出为什么，但会感到每一话"更整齐了"——扩张不靠情节讲，靠画法讲。交稿逐话检查。

### 3.4 人机不同格（V2 全采）+ 三形态白名单（V3）+ 验收题（V4）

- 智子只以三种形态入画：屏幕文字（可出血出格——人在框内，系统在框外）、无来源话框（全书仅董事会与车库广播两处，等大、无尾、零表现力）、物理后果（后果格内不得出现执行者——没有手、没有影子、没有"正在操作"的暗示）
- 人机不同格：纸书轨同条漫轨，人机同格全书只给三次——董事会、车库告知、（冷开若采用则加序章）——三次即三个顶点
- 终检题：试片读者被问"智子长什么样"，答案必须是"没有样子"。任何人画出脸、人形、眼睛，整体返工

## 4. 分镜与工艺（V3 为基）

- **格律**：G1 匀格（机构时间，55%）/ G2 横幅（物理匀速时间，25%）/ G4 竖切（人的时间被打乱，12%）/ G3 整页跨页（仅翻页落点与特殊页，6%）+ 字格、空镜格。一页一种格型，换格型只在换场景处
- **六个固定机位站**：玄关衣架 / 街口斑马线 / 张三工位 / 车间猫道 / 王五与机器 / 车库。同一文件复制改画，逐像素同源。其中**街口站升级为计数字幕制度**（V4）：六次出现，字幕只出时间戳与系统计量，从行人 14,203 数到行人 0
- **隐藏后拉镜头**：桌面→楼层→路口→厂区→地图→城市→海岸→月面。机位属于叙述者，永不属于智子——全书不存在任何"它看到的画面"
- **翻页节拍谱**：11 处落点全锁右页，其中 5 处刻意是纯文字页（提示词×2、kubectl 回显、"性价比不高"、空白登记簿）。文字页抢走图像的高潮位——这个"抢"本身就是主题
- **零拟声词**：全书无"轰""咔哒"。机器的世界是静音的，静音是恐惧的来源。唯一近似声音的是闪动对格（双闪/检测灯/雨刮"一下，一下"/红点），全书限五处
- **物件签名制**：张三=工牌+未读红点、李梅=文件夹、王五=截图、素芬=工牌、小唐=蛋糕订单页、赵工=奶茶杯→磨豆机、老葛=枸杞杯、参谋=笔记本。转场优先切物不切脸
- **章扉工单制**（V3 R4）：每章章扉是放大的系统文档（迭代通知/审批单/优化名单/检修单/登记簿），关键字段以"……"隐去——文档感垫在全书翻页之间

## 9. 铁律总自查（每话/每章过稿前，责编执行）

1. 智子是否只以屏幕文字/无来源话框/物理后果三种形态出现？有无第四形态（含图标、Logo、任何形象暗示）？
2. 旁白与分镜笔记跑禁词检索：想/觉得/选择/决定/知道/需要/姿态/注意力/等/识别/抵御——凡主语为智子一律改功能性表述
3. 提示词三处是否同版式、一字一标点不差？除三处完整呈现外全书是否无整句引用？
4. 高光台词砸点表逐句 grep 回归：性价比不高/它不还手，它就是不配合/我说它/没有火，没有墙/爸爸晚安/我看着/车从来不应他/你们行啊——原样落格，禁加感叹号
5. 军事画面零国别标识？真实品牌已架空化？灭绝段无死亡画面？
6. 增写内容是否全部在人类侧（生活细节、过渡动作）？有无新增任何智子行为与台词？
